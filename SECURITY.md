# Security

Do not report security vulnerabilities in a public issue. Contact
hello@naavos.radoss.agency with a concise description and reproduction steps.

Never include passwords, API keys, OAuth codes, bearer tokens, private Avatar
records, or unredacted logs in a report. Radoss stores provider credentials in
the operating-system credential store and keeps them out of setup state,
generated agent configuration, diagnostics, and source control.

The public package and source checks are not a guarantee of customer-release
readiness. Hosted OAuth, tenant isolation, signed distribution, and human host
acceptance remain separate evidence gates.
